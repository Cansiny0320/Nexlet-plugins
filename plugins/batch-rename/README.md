# 批量重命名

需要 Nexlet 0.2.47+。支持查找替换、前后缀、追加编号及 `{name}-{n}{ext}` 文件名模板。先预览，再执行；只在文件原目录修改名称。

执行前再次检查文件身份、内容和目标占用。操作日志写入插件数据目录；部分失败或取消后可用“恢复原名”，成功后可撤销。若文件被外部修改或原名被其他文件占用，恢复会停止并保留日志。关闭／禁用插件后，可重新打开查看恢复操作。

界面最多接收 100 个文件，单个文件不超过 256 MiB，总计不超过 1 GiB。仅支持普通文件，不支持文件夹和符号链接。安全移动依赖文件系统硬链接支持；不支持的卷会报告失败。重命名过程中避免其他程序修改这些文件。无网络权限。
