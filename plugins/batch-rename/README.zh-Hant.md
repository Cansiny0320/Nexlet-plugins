# 批次重新命名

需要 Nexlet 0.2.47+。支援查詢替換、前後綴、追加編號及 `{name}-{n}{ext}` 檔名模板。先預覽，再執行；只在檔案原目錄修改名稱。

執行前再次檢查檔案身份、內容和目標占用。操作日誌寫入外掛資料目錄；部分失敗或取消後可用“恢復原名”，成功後可撤銷。若檔案被外部修改或原名被其他檔案佔用，恢復會停止並保留日誌。關閉／停用外掛後，可重新開啟檢視恢復操作。

介面最多接收 100 個檔案，單個檔案不超過 256 MiB，總計不超過 1 GiB。僅支援普通檔案，不支援資料夾和符號連結。安全移動依賴檔案系統硬連結支援；不支援的卷會報告失敗。重新命名過程中避免其他程式修改這些檔案。無網路許可權。
