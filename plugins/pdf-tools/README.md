# PDF 工具

需要 Nexlet 0.2.47+。支持合并、拆分、提取／重排、旋转页面、图片转 PDF 和 PDF 转 PNG。通过启动器传入文件或图片，或在插件内添加文件。

页码支持 `1-3,5,2` 和倒序；留空表示全部。旋转只改变选定页面的方向，保留其他页面。拆分和渲染处理列表中的第一个 PDF。图片转 PDF 会将图片转为 PNG 后嵌入。

单文件不超过 16 MiB；PDF 不超过 1000 页；单次渲染不超过 100 页、单页不超过 3600 万像素。生成文件不覆盖已有路径；拆分／渲染写入新目录。取消后保留已经输出的文件，并显示结果路径。加密、损坏或超限文件会报错，不承诺保留数字签名和 PDF 表单功能。

处理在本机完成，无网络权限。依赖 pdf-lib（MIT）和 PDF.js（Apache-2.0），构建包保留第三方许可证。
