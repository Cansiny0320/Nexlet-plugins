# PDF 工具

需要 Nexlet 0.2.47+。支援合併、拆分、提取／重排、旋轉頁面、圖片轉 PDF 和 PDF 轉 PNG。通過啟動器傳入檔案或圖片，或在外掛內新增檔案。

頁碼支援 `1-3,5,2` 和倒序；留空表示全部。旋轉只改變選定頁面的方向，保留其他頁面。拆分和渲染處理列表中的第一個 PDF。圖片轉 PDF 會將圖片轉為 PNG 後嵌入。

單檔案不超過 16 MiB；PDF 不超過 1000 頁；單次渲染不超過 100 頁、單頁不超過 3600 萬畫素。生成檔案不覆蓋已有路徑；拆分／渲染寫入新目錄。取消後保留已經輸出的檔案，並顯示結果路徑。加密、損壞或超限檔案會報錯，不承諾保留數字簽名和 PDF 表單功能。

處理在本機完成，無網路許可權。依賴 pdf-lib（MIT）和 PDF.js（Apache-2.0），構建包保留第三方許可證。
