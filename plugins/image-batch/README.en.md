# Image batch

Requires Nexlet 0.2.47+. Export PNG, JPEG or WebP; resize proportionally, compress, add text watermarks and create grid collages. Pass images/files from the launcher or select local images.

Preview the first image before processing the batch. Zero maximum width/height leaves that dimension unrestricted. Small images are not enlarged. JPEG transparency becomes white. Watermarks appear at the lower right; collage cells preserve aspect ratios.

Limits: 100 images, 36 million pixels per image and 16 MiB per output. Output goes to a new folder, preserving originals. Cancellation retains completed files; failures are listed individually. Processing is local, with no network permission.
