# 文字表格转图片

用户于 2026-10-19 批准以下设计。实现位于 Nexlet-plugins，宿主仅新增通用剪贴板 HTML 读取能力。

## 用户流程

复制文字或 Excel 单元格区域，打开「文字表格转图片」，自动读取并预览；也支持粘贴以及编辑纯文字。顶部提供读取剪贴板、复制图片、保存 PNG，侧边提供字号、图片宽度、内边距、背景色。默认白底、2 倍像素输出，界面适配窄窗口和深浅主题。

Excel HTML 转换保留单元格文字、字体、颜色、边框、对齐、合并关系和可支持的尺寸。不存在 HTML 表格时按 TSV 还原基础表格；普通文字保留换行。图表、浮动图片、公式计算和逐像素复刻 Excel 不在本次范围。内容只在内存中处理，不联网、不持久化。

## 架构和合同

- Nexlet 增加 `nexlet.clipboard.readHTML(): Promise<string | null>`，需要 `clipboard.read`。无 HTML 返回 null，超过 2 MiB 拒绝而不截断；返回值不可信，插件负责清理。
- 新插件 `org.nexlet.text-image` 位于 `plugins/text-image/`，权限为 `clipboard.read`、`clipboard.write`、`files`（PNG 保存对话框和写入）。
- 旧宿主缺少 readHTML 时仍支持文字读取和粘贴事件中的 HTML，并提示如何保留表格样式。
- 在惰性 HTML 模板中解析输入，仅重建表格、行、单元格和文字。通过 CSS 白名单提取 Excel 样式，丢弃脚本、事件、链接、图片、嵌入内容和外部资源。绝不把原始剪贴板 HTML 插入活动文档。
- 使用浏览器排版清理后的文字/表格，经 SVG foreignObject 和 Canvas 生成 PNG；预览直接显示生成的 PNG。不扩展宿主 CSP 或授予网络权限。
- 100,000 字符、5,000 单元格以及导出尺寸/像素/文件大小限制防止无界内存分配；不静默截断。异步导出使用版本号，旧任务不能覆盖新输入。

## 验收

纯文字/中文/多行/空白/长行、Excel 样式和合并单元格、引号包裹的多行 TSV、恶意 HTML 和 CSS、空剪贴板、大表格拒绝、异步编辑、复制 PNG、保存 PNG 和取消保存。真实 Electron 中验证安装包、宿主 HTML API 权限和限制、深浅主题和窄窗口。真实 Excel 应用未参与时明确说明样式兼容依据为剪贴板格式样例。
