# 插件自动发布与 Ctool 上架

用户已批准：插件合入 main 后自动校验、打包、发布并更新市场；不需要宿主发版或手动标签。此次包含 Ctool 上架，允许提交、推送及实际发布。

- `catalog.json` 保存待发布插件的目录、作者、分类、平台和最低宿主版本；名称、描述、版本来自插件 manifest。`index.json` 只保存已经可下载的市场版本，地址与 schema 保持兼容。
- PR 只校验。main 推送及 main 手动重试自动发布。每个插件使用独立的不可覆盖版本和 Release；旧插件保留已有下载地址。
- 构建、测试通过后上传，校验远端文件大小与 SHA-256，公开 Release 并验证匿名下载，最后一次性更新市场目录及发布状态。
- 同版本源码改变必须递增 manifest 版本。发布状态记录源码摘要；首次迁移现有三个插件时保留历史 Release，建立当前源码基线。
- 发布串行，发布前后核对 main 的提交；索引通过普通快进 push 更新，拒绝旧任务覆盖新提交。失败不移动市场目录，已上传的相同版本可安全重试。
- Ctool 使用当前已发布 Nexlet 0.2.21 作为保守的最低版本，并对该版本验证实际包的运行。此次不承诺更早宿主兼容性。
- 不改变客户端，不替换用户日常插件或数据。回滚通过恢复旧索引/发布状态进行，保留历史资产；后续修复使用更高版本。
